# Турк Бөөний Барааны Агуулах

Туркээс импортолсон барааны бөөний худалдааны бүтээгдэхүүний каталог (демо).

## Боломжууд
- Бүтээгдэхүүн хайх, ангиллаар шүүх, үнээр эрэмбэлэх
- Бүтээгдэхүүний дэлгэрэнгүй цонх, тоо ширхэг сонгох
- Сагс: нэмэх, тоо өөрчлөх, хасах (хөтөчид хадгалагдана)
- Захиалгын форм: нэр, утас, хаяг, нэмэлт тайлбар, төлбөрийн хэлбэр
- Төлбөрийн хэсэг (демо, бодит төлбөр хийгдэхгүй)
- Админ демо (`/admin`): бараа нэмэх, засах, устгах, зураг солих, үнэ өөрчлөх, захиалга харах

## Үнэ, бараа засах
Бүх бараа `js/data.js` файлд байна. Үнэ (`price`), нэр, тайлбар, зураг (`image`)-ийг тэндээс засна.
Админ хэсэгт хийсэн өөрчлөлт зөвхөн тухайн хөтөч дээр хадгалагдана. «Өгөгдөл татах» товчоор
шинэ `data.js` файл аваад репод солих замаар бүх хэрэглэгчид харуулна.

## Ажиллуулах
Build шаардлагагүй статик сайт. Локалд: `python3 -m http.server 8080` гээд http://localhost:8080 нээнэ.
Vercel дээр репог холбоход автоматаар deploy хийгдэнэ.

бүтээгдэхүүний дэлгэрэнгүй цонхонд харуулсан.
